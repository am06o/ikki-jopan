# 글꼴

이 폴더의 글꼴은 MIT 라이선스가 아니라 **KoPub/KoPubWorld 서체 라이선스**(LICENSE.md)를 따릅니다.

- 원본: KoPubWorld 바탕체, 돋움체 (저작권 문화체육관광부, 한국출판인회의), npm `font-kopubworld` 1.0.3
- 수정 내용: 한글 11172자, 영문, 자주 쓰는 문장부호와 기호만 남기고 woff2로 바꿈
- 라이선스 제4조 ②에 따라 수정본의 서체 이름을 바꿈: 이끼 바탕 (Ikki Batang), 이끼 돋움 (Ikki Dotum)
- 무료로만 쓸 수 있고, 판매 등 상업적 행위는 금지 (제4조 ①)
- 남긴 글자 밖의 글자(한자 등)는 웹 페이지가 원본 KoPubWorld를 jsDelivr에서 받아 씁니다
